# dns-server
Very stupidly bad DNS server written in pure C with [nob](https://github.com/tsoding/nob.h).
Came to be because I wanted to see if I could have a fast and easy way of having DNS on Wireguard, and to learn DNS more intimately.  
Builds with GNU `make`, binary `bin/dns_server` will be generated.  

```
Usage: dns_server [-h host] [-p port] [-z zonefile]

-h host             any IPv4 literal, default 0.0.0.0
-p port             any positive number 1-65535, randomly generated by default
-z zonefile         path to a "zone file", see [the](./test-zone) [repo](./wg-zone) for examples
```
